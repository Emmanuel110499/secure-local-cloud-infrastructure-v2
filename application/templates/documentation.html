Qu’est-ce que cette plateforme ?

Une interface unique pour comprendre l’état d’une infrastructure informatique.

Secure Local Cloud Infrastructure est une plateforme de supervision. Elle rassemble sur une même interface les informations importantes concernant les serveurs, les applications, les conteneurs et la sécurité.

Voir l’état général

Vous savez rapidement si la plateforme fonctionne normalement ou si une anomalie nécessite une vérification.

Centraliser les informations

Il n’est pas nécessaire de consulter plusieurs outils séparés pour comprendre la situation.

Suivre les performances

Les ressources principales du serveur sont affichées sous forme d’indicateurs et de graphiques faciles à lire.

Être assisté

Emma_IA peut expliquer les informations présentées et aider à identifier un problème.

La plateforme ne remplace pas l’administrateur. Elle lui permet de voir plus rapidement ce qui se passe et de prendre de meilleures décisions.

Comprendre les indicateurs

Ces valeurs montrent comment le serveur utilise ses ressources.

CPU Il représente l’effort demandé au processeur. Une valeur très élevée pendant longtemps peut indiquer une surcharge.
Mémoire Elle correspond à la RAM utilisée par les applications actuellement en fonctionnement.
Disque Il indique la part de l’espace de stockage déjà utilisée sur le serveur.
Uptime Il indique depuis combien de temps le serveur fonctionne sans redémarrage.
Une valeur ponctuellement élevée n’est pas toujours un problème. C’est surtout une valeur élevée pendant une longue période qui mérite une analyse.
🐳

Les conteneurs Docker

Des espaces indépendants dans lesquels fonctionnent les applications.

Un conteneur peut être comparé à une petite boîte contenant une application et tout ce dont elle a besoin pour fonctionner. Plusieurs conteneurs peuvent fonctionner sur le même serveur sans se mélanger.

Nom

Permet de reconnaître l’application ou le service exécuté dans le conteneur.

État

« Running » signifie que le conteneur est actuellement en fonctionnement.

CPU et mémoire

Montrent la quantité de ressources consommées par chaque conteneur.

Uptime

Indique depuis combien de temps le conteneur est en cours d’exécution.

Les boutons de démarrage, d’arrêt et de redémarrage modifient réellement l’état d’un conteneur. Une confirmation est donc demandée avant chaque action.
🔎

La supervision et les graphiques

Observer l’évolution de la plateforme dans le temps.

Prometheus

Prometheus récupère régulièrement les informations concernant les serveurs, les services et les conteneurs.

Grafana

Grafana transforme les informations collectées en graphiques et en tableaux faciles à lire.

Node Exporter

Il fournit les informations principales du serveur, comme le processeur, la mémoire et le disque.

cAdvisor

Il observe spécifiquement les ressources consommées par les conteneurs Docker.

En résumé : les outils de collecte récupèrent les informations, Prometheus les conserve et Grafana les présente sous forme de graphiques.
🔐

La sécurité expliquée simplement

Plusieurs protections travaillent ensemble pour limiter les accès non autorisés.

Connexion sécurisée

Le protocole HTTPS chiffre les échanges entre le navigateur et la plateforme.

Authentification

L’utilisateur doit fournir un identifiant et un mot de passe valides pour accéder aux pages protégées.

Pare-feu

UFW bloque les connexions entrantes qui n’ont pas été explicitement autorisées.

Protection SSH

Fail2ban repère les tentatives répétées de connexion et bloque temporairement leur origine.

Cloudflare Zero Trust

Il ajoute un contrôle d’accès avant même que l’utilisateur n’atteigne directement la plateforme.

Alertes

Alertmanager permet de transmettre une alerte lorsqu’une situation anormale est détectée.

Emma_IA

L’assistant intégré qui explique les données de la plateforme.

Emma_IA peut répondre à des questions formulées avec des mots simples. Elle utilise les informations actuelles de la plateforme et la documentation locale pour fournir une réponse adaptée.
1

Posez une question

Exemple : « Mon infrastructure est-elle saine ? »

2

Emma_IA analyse les données

Elle consulte les métriques, les services et les conteneurs disponibles.

3

Elle présente une réponse lisible

La réponse indique les constats, les éventuels risques et les vérifications recommandées.

Emma_IA possède un accès en lecture uniquement. Elle ne redémarre, n’arrête et ne supprime aucun service.

Historique et journal d’audit

Savoir qui a réalisé une action et à quel moment.

Le journal d’audit conserve la trace des opérations administratives effectuées depuis la plateforme, notamment les actions réalisées sur les conteneurs.

Date

Indique le moment précis auquel l’action a été demandée.

Utilisateur

Permet de savoir quel compte était connecté lors de l’opération.

Ressource

Identifie le conteneur ou le composant concerné par l’action.

Résultat

Indique si l’opération s’est terminée avec succès ou si elle a échoué.

Glossaire

Définitions simples des mots utilisés dans la plateforme.

Serveur Ordinateur chargé d’exécuter des applications et de fournir des services.
Infrastructure Ensemble des serveurs, réseaux, applications et outils nécessaires au fonctionnement d’un système informatique.
Docker Outil permettant d’exécuter des applications dans des environnements isolés.
Conteneur Environnement isolé dans lequel une application fonctionne.
Image Docker Modèle utilisé pour créer un ou plusieurs conteneurs.
CPU Processeur chargé d’effectuer les calculs nécessaires au fonctionnement du serveur.
RAM Mémoire temporaire utilisée par les applications actuellement ouvertes.
Métrique Valeur mesurée permettant de suivre l’état ou les performances d’un système.
Monitoring Surveillance continue d’une infrastructure et de ses ressources.
Service Programme fonctionnant en arrière-plan pour fournir une fonctionnalité précise.
HTTPS Protocole qui chiffre la communication entre le navigateur et la plateforme.
Journal d’audit Historique des opérations réalisées sur la plateforme.
